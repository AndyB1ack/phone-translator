# Переводчик для телефона (иврит / английский ⇄ русский)

Страница для живого разговора: телефон лежит между собеседниками, экран разделён пополам,
верхняя половина перевёрнута к собеседнику.

- 🎯 **По фразам**: нажал → сказал → нажал; распознавание (gpt-4o-transcribe) → перевод (gpt-4.1-mini) → озвучка (gpt-4o-mini-tts).
- ⚡ **На лету**: gpt-realtime-translate по WebRTC, перевод звучит, пока человек говорит; по каналу на каждое направление, звук шлётся только пока нажата кнопка.
- Субтитры в обоих режимах, учёт расходов (оценка), экран не гаснет.

Ключ OpenAI вводится в ⚙︎ и хранится только в браузере телефона (localStorage) — в коде его нет.
Рекомендуется отдельный ключ с лимитом расходов.
